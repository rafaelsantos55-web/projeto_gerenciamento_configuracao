# Requisitos do projeto demonstrativo

## Objetivo funcional
Manter uma lista simples de artefatos de software, identificando nome, categoria e versão.

## Requisitos
- RF01: listar os artefatos cadastrados.
- RF02: apresentar um resumo com a quantidade de artefatos e a versão do programa.
- RNF01: manter o código organizado e legível.
- RNF02: permitir execução em Python 3.10 ou superior.

## Controle de configuração
Cada alteração relevante deve ser registrada em commit com mensagem objetiva. O repositório remoto é a referência compartilhada da equipe após a publicação autenticada.
